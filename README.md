# 🎲 Real Ludo - প্লেয়ার ইউজার অ্যাপ (User App Source Code)
> ⚡ **লেটেস্ট আপডেট করা কোড** | জেনারেটের সময়: ৭/১১/২০২৬, ৯:৫৭:০৭ AM (2026-11-07T03:57:07.623Z)

এটি Real Ludo প্ল্যাটফর্মের সম্পূর্ণ প্লেয়ার অ্যাপ্লিকেশন। এতে টুর্নামেন্ট ম্যাচ লিস্ট, বিকাশ/নগদ ডিপোজিট, উইথড্র রিকোয়েস্ট, রুম কোড লাইভ চ্যাট, পুশ নোটিফিকেশন ও প্রোফাইল সিস্টেম অন্তর্ভুক্ত রয়েছে।

এই প্রজেক্টটি **গুগল স্টুডিও, Netlify, কম্পিউটার (পিসি) এবং মোবাইল (Acode/Browser)** - যেকোনো জায়গায় ১০০% চলবে।

---

### 💻 ১. কম্পিউটারে (PC / VS Code) রান করার নিয়ম:
১. এই ZIP ফাইলটি আনজিপ করুন।
২. ফোল্ডারটি **VS Code** এ ওপেন করুন।
৩. টার্মিনাল খুলে ডিপেন্ডেন্সি ইনস্টল করতে কমান্ড দিন:
```bash
npm install
```
৪. লোকাল ডেভেলপমেন্ট সার্ভার চালু করতে:
```bash
npm run dev
```
৫. ব্রাউজারে **http://localhost:3000** ওপেন করুন।
৬. প্রডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```
*(১০০% কোনো এরর ছাড়াই `dist/` ফোল্ডারে অপ্টিমাইজড বিল্ড তৈরি হবে)*

---

### 🌐 ২. Netlify তে ডিপ্লয় করার নিয়ম:
- **Netlify Drop (তাত্ক্ষণিক):**
  1. আপনার পিসিতে `npm run build` কমান্ড দিন।
  2. তৈরি হওয়া `dist` ফোল্ডারটি সরাসরি [app.netlify.com/drop](https://app.netlify.com/drop) এ ড্রপ করুন।
- **Git Repo Deployment:**
  - Build command: `npm run build`
  - Publish directory: `dist`
  *(প্রজেক্টে ইতিমধ্যে `netlify.toml` ও `public/_redirects` যুক্ত আছে, তাই কোনো 404 এরর আসবে না)*

---

### 📱 ৩. Android ফোনে Acode অ্যাপ দিয়ে চালানো:
১. প্লে স্টোর থেকে **Acode** অ্যাপটি ইনস্টল করুন।
২. জিপটি ফোনে আনজিপ করে Acode এ **Open Folder** নির্বাচন করুন।
৩. টার্মিনাল থাকলে `npm install && npm run dev` দিয়ে সরাসরি টেস্ট করুন।

---

### 📱 ৪. Android Studio দিয়ে নেটিভ APK বিল্ড:
```bash
npx cap sync android
npx cap open android
```
অথবা টার্মিনালে `./build-apk.sh` রান করুন।
